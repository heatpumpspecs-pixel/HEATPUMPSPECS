This is an intake manifest for two user-supplied ZIP archives. It is not the canonical TechSpecs source inventory and it is not a set of V2 product records.

- 16 PDF reports across 2 certificate holders.
- 241 PDF pages in total.
- Text extraction succeeded for the inspected PDFs.
- SHA-256 values identify the exact PDF bytes in the supplied ZIP archives.
- Source URLs were not present in the ZIPs and are deliberately left blank; they must be captured from the KEYMARK directory.
- Original PDF binaries have not yet been committed to this repository.
- Technical field extraction, exact model reconciliation, schema mapping and factual verification remain outstanding.

The uploaded archive names and original PDF filenames are retained in the CSV. Do not treat one report/subtype as one final product record without reconciling the report's model tables.
